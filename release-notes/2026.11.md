# Release Notes - Version 2026.11

**Release Date:** November 2026

Version 2026.11 introduces our official product rebrand to **Chicken Fork**, comprehensive native Microsoft Remote Desktop (RDP) connection support via FreeRDP 3.32.2, updated JPEG codecs, and refined macOS integration.

---

## 🚀 Highlights & Major Features

### 🖥️ Native Microsoft Remote Desktop (RDP) Integration
* **FreeRDP 3.32.2 Integration**: Integrated FreeRDP 3.x and OpenSSL 3.x static libraries for native, hardware-accelerated RDP connections alongside classic VNC/RFB.
* **Modern Windows Server Compatibility**: Supports Network Level Authentication (NLA / CredSSP), TLS encryption, and standard RDP security protocols for modern Windows Server and Windows 10/11 desktops.
* **Cursor Synchronization & Shortcuts**: Full mouse pointer shape synchronization and macOS-to-Windows keyboard shortcut mapping.
* **Dynamic Resolution & Graphics**: Enhanced display pipeline with EGFX / RFX support for smooth rendering and high responsiveness.

### ⚡ Codec Upgrades & Performance
* **libjpeg-turbo v3.2.0**: Upgraded static TurboJPEG library to version 3.2.0 for faster TightVNC encoding decompression on Apple Silicon and modern Intel CPUs.
* **Optimized Swift Bridge**: Realigned Swift-Objective-C interoperability bridging (`ChickenFork-Swift.h`) and optimized cryptographic routines.
