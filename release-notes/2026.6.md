# Release Notes - Version 2026.6

**Release Date:** June 2026

Version 2026.6 represents the major modernization of *Chicken of the VNC* into **ForkOfTheChickenOfTheVNC (FotCotVNC)**, updating the legacy 2.2b3 codebase for modern 64-bit macOS systems and Apple Silicon.

---

## 🚀 Highlights & Major Modernizations

### 🖥️ Display & Framebuffer Performance
* **Dynamic Desktop Resizing**: Added support for resizable session windows when connected to VNC servers that support dynamic desktop resizing (while honoring view-only modes).
* **Retina / High-DPI Display Stability**: Fixed an off-by-one boundary checking bug in framebuffer drawing (`FrameBufferDrawing`) that caused out-of-bounds bitmap memory access and crashes on high-DPI and Retina screens.
* **Workspace & Occlusion Tracking**: Modernized window state tracking to use `NSWindowOcclusionStateVisible`, fixing corrupted screen artifacts when switching between macOS virtual Spaces.
* **Native macOS Fullscreen**: Modernized fullscreen behavior to leverage native macOS Spaces fullscreen capabilities.

### 📋 Clipboard Synchronization & UTF-8
* **Extended-Clipboard Protocol Support**: Implemented the VNC "extended-clipboard" protocol extension, enabling seamless copy-paste of Unicode / UTF-8 multi-byte characters between macOS and remote sessions.
* **Automatic Clipboard Sync**: Automatically synchronizes clipboard contents when a session window gains focus or right before sending middle-click events.

### ⚙️ Apple Silicon & Universal Binary Architecture
* **Apple Silicon & Intel Universal App**: Fully modernized build pipeline to produce native Universal binaries (`arm64` and `x86_64`).
* **libjpeg-turbo v3.1**: Upgraded underlying JPEG compression libraries to modern `libjpeg-turbo` static universal binaries for enhanced rendering speed and low latency.
* **Dropped Legacy 32-bit Code**: Cleaned up obsolete PowerPC / 32-bit routines and modernized deployment targets for modern macOS versions (11.0+).

### 🐛 Stability, UI & Bug Fixes
* **Apple Silicon Table Selection Fix**: Fixed connection list selection row data types on ARM64 architectures that previously caused navigation glitches.
* **SSH Tunnel Crash Fix**: Fixed a crash condition caused by SSH tunnel setup failure.
* **Memory & Resource Leaks**: Plugged memory leaks, fixed duplicate mouse tracker releases, and updated deprecated Cocoa APIs across the codebase.
* **String Catalog Localization**: Modernized localized strings using Xcode String Catalogs (`.xcstrings`).
* **Removed Legacy Sparkle Updater**: Removed outdated Sparkle framework and manual update check components.

### 🎨 Visual & Branding Refresh
* **FotCotVNC Branding**: Introduced new app branding, updated About dialogs, documentation, and ultra-high-resolution "Liquid Glass" iconography.
