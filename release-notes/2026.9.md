# Release Notes - Version 2026.9

**Release Date:** August 2026

Version 2026.9 brings major functionality upgrades, modern macOS compatibility enhancements, Touch Bar integration, and important bug fixes.

---

## 🚀 Highlights & Major Features

### 🎛️ Touch Bar Support
* **Native Touch Bar Integration**: Added full Touch Bar support on compatible MacBook Pro models. Easily switch between active sessions, trigger quick connections to saved servers, and access session actions right from the keyboard.
* **Smart Connection Tracking**: Refined connection state tracking and dynamic button indicator highlights across multiple active sessions.

### 🔐 Apple Remote Desktop (ARD) & Modern macOS VNC Authentication
* **Apple ARD Authentication Extension**: Integrated support for the Apple Remote Desktop authentication extension (Diffie-Hellman Key Exchange and AES/RSA encryption via CryptoSwift).
* **Connect to Modern macOS Hosts**: Connect seamlessly to recent macOS Screen Sharing / Remote Management servers using standard macOS user credentials.

### 🔑 Passphrase-Protected SSH Key Guidance
* **Clear User Notifications**: Added detection and informative alerts when an SSH private key requires a passphrase.
* **Keychain & SSH-Agent Instructions**: Chicken now provides step-by-step guidance on adding passphrase-protected keys to the macOS Keychain (`ssh-add --apple-use-keychain`) or SSH agent to prevent hangs or silent connection drops.

### 🖥️ Fullscreen Space & Window Management Fixes
* **Prevent Fullscreen Space Hijacking**: Fixed an issue where opening a new connection window (via Touch Bar, menus, or dialogs) while an existing connection was in native fullscreen would pull the new window into the fullscreen Space as an unwanted tab or overlay.
* **Window Tabbing Controls**: Disabled automatic window tabbing and restored proper window collection behaviors across sessions.

### ⚡ Protocol, Handshake & Discovery Improvements
* **Handshake Reliability**: Prevented premature clipboard synchronization during initial RFB handshakes to eliminate connection setup race conditions.
* **Diagnostics & Logging**: Added comprehensive connection and handshake logging for easier debugging.
* **Bonjour / Rendezvous Fixes**: Fixed synchronization issues with local Bonjour / Rendezvous server discovery.

### 🛠️ Architecture, Modern XIBs & Code Cleanup
* **XIB Interface Conversion**: Migrated legacy binary NIB files to modern `.xib` files with automated compilation during release builds.
* **Modern Compiler & Keychain Warnings**: Updated legacy Security and Keychain APIs to modern equivalents and resolved compiler deprecation warnings across the codebase.
* **Universal Binary Builds**: Optimized project configuration and release scripts to ensure clean Universal (`arm64` + `x86_64`) builds.
