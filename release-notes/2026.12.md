# Release Notes - Version 2026.12

**Release Date:** December 2026 (In Development)

Version 2026.12 upgrades the native Remote Desktop (RDP) engine to FreeRDP 3.33.0 with Apple VideoToolbox hardware-accelerated H.264 decoding and enhanced graphics pipelines.

---

## 🚀 Highlights & Major Features

### 🖥️ FreeRDP 3.33.0 Engine Upgrade
* **Upgraded FreeRDP Static Libraries**: Updated bundled universal static libraries (`arm64` and `x86_64`) and headers to FreeRDP 3.33.0, incorporating the latest protocol fixes, stability improvements, and CVE security patches.
* **Apple VideoToolbox Hardware H.264 Decoding**: Built FreeRDP with `-DWITH_APPLE_VIDEOTOOLBOX=ON` and linked `VideoToolbox.framework`, `CoreMedia.framework`, and `CoreVideo.framework`. RDP sessions now decode modern H.264 video streams directly using Apple hardware decoders on Apple Silicon and Intel Macs.
* **Modern RDPEGFX AVC420 & AVC444 Support**: Enabled `FreeRDP_GfxH264`, `FreeRDP_GfxAVC444`, and `FreeRDP_GfxAVC444v2` in the connection pipeline for high-fidelity, low-latency display updates when connecting to modern Windows 10/11 and Windows Server hosts.

### 🛠️ Build & Integration
* **Universal Build Script Enhancements**: Updated `scripts/build_freerdp_mac.sh` to target FreeRDP 3.33.0 with VideoToolbox hardware acceleration and local workspace repository detection.
* **Xcode Project Modernization**: Added Apple VideoToolbox, CoreMedia, and CoreVideo frameworks to Chicken Fork build settings.
