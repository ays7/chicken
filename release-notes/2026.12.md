# Release Notes - Version 2026.12

**Release Date:** December 2026 (In Development)

Version 2026.12 upgrades the native Remote Desktop (RDP) engine to FreeRDP 3.33.0 with Apple VideoToolbox hardware-accelerated H.264 decoding, ultra-responsive dynamic cursor handling, and enhanced graphics pipelines.

---

## 🚀 Highlights & Major Features

### 🖥️ FreeRDP 3.33.0 Engine Upgrade
* **Upgraded FreeRDP Engine**: Updated bundled universal static libraries (`arm64` and `x86_64`) to FreeRDP 3.33.0, incorporating the latest protocol fixes, stability improvements, and security patches.
* **Apple VideoToolbox Hardware H.264 Decoding**: RDP sessions now decode modern H.264 video streams directly using Apple hardware decoders on Apple Silicon and Intel Macs, significantly reducing CPU usage and latency.
* **Modern High-Fidelity Graphics**: Enabled modern RDPEGFX display pipelines (including AVC420 and AVC444) for crisp text, vibrant colors, and low-latency display updates when connecting to Windows 10/11 and Windows Server hosts.

### 🖱️ Fluid Remote Cursor & Mouse Tracking
* **Instant Cursor Shape Transitions**: Dynamic mouse cursors (such as text I-beams, resize arrows, and pointing hands) now change shape immediately as the pointer moves across buttons, text fields, and window borders, eliminating cursor lag and flickering.
* **Smooth Mouse Motion & Responsiveness**: Optimized pointer movement delivery to eliminate lag and prevent network congestion, ensuring clicks, drag gestures, and navigation feel fast and fluid.
* **Optimized Remote Cursor Rendering**: Tuned remote pointer performance settings to reduce rendering overhead on Windows hosts.

### 🛠️ Build & Architecture
* **Streamlined Universal Builds**: Modernized build scripts and project configurations to ensure seamless native compilation and hardware acceleration across both Apple Silicon and Intel Macs.
* **Native Framework Integration**: Integrated modern macOS media and video frameworks to power hardware-accelerated RDP display pipelines.
