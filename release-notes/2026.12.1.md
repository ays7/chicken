# Release Notes - Version 2026.12.1

**Release Date:** November 16, 2026

Version 2026.12.1 introduces hardware-accelerated Metal rendering, native Retina/HiDPI display scaling for RDP, Windows LAN RDP discovery, Fit-to-Window and 1:1 scaling modes for VNC/ARD, instant Apple Remote Desktop authentication, macOS trust store certificate verification for RDP, and a full migration to Automatic Reference Counting (ARC).

---

## 🚀 Highlights & Major Features

### 🎨 Metal Rendering & Display Scaling
* **Metal GPU Rendering**: Switched remote desktop rendering from CPU-bound Core Graphics to an on-demand Apple Metal pipeline (with automatic Core Graphics fallback when Metal is unavailable), delivering smoother frame updates, lower CPU usage, and improved battery life.
* **Retina & High-DPI Support for RDP**: Added an opt-in **Optimize for Retina displays** option with configurable scaling (`Auto`, `100%`, `150%`, `200%`), dynamic DPI renegotiation when moving windows between Retina and standard displays, and per-monitor DPI in "Use all screens" multi-monitor mode.
* **Mixed-DPI Multi-Monitor Dragging**: Fixed cursor and drag coordinate mapping when dragging across monitors with mixed Retina (`2x`) and standard (`1x`) scaling in multi-monitor full-screen RDP sessions.
* **Fit-to-Window & Actual Size (1:1) Scaling Modes**: Added **Fit to Window** (default) and **Actual Size (1:1)** display scaling modes for fixed-resolution VNC and Apple Remote Desktop (ARD) sessions, accessible from the session window titlebar and **Connection** menu (`Cmd+9` / `Cmd+0`) and remembered per host.
* **Initial VNC Window Sizing**: Fixed an issue where VNC session windows could shrink unexpectedly during initial setup and restoration.

### 🌐 Network Discovery & Connection Experience
* **Windows LAN RDP Discovery**: Added active local-network discovery for Windows Remote Desktop hosts over IPv4, resolving hostnames via mDNS, reverse DNS, NetBIOS, LLMNR, MSRPC, and RDP TLS certificates while explicitly skipping VNC ports to avoid probing unencrypted services.
* **Unified Scan & Bonjour Discovery**: Unified Bonjour VNC browsing under the Connection Dialog's **Scan / Stop** button (removing automatic background scanning on launch and the separate Bonjour toggle) while retaining discovered hosts until the next scan.
* **Saved Server Deduplication**: Automatically excludes discovered RDP and Bonjour VNC hosts that match already-configured server bookmarks (including custom DNS hostnames and IP addresses) to prevent duplicate entries in the server list.
* **Instant Apple Remote Desktop (ARD) Authentication**: Offloaded 4096-bit Diffie-Hellman key exchange to OpenSSL on a background queue, reducing ARD handshake latency from several seconds to milliseconds without blocking the UI.

### 🔒 Security, Trust & Modernization
* **macOS Trust Store Certificate Verification for RDP**: Replaced silent TLS certificate acceptance with native macOS trust evaluation against the real target hostname (including over SSH tunnels), presenting Apple's standard certificate trust panel when untrusted so users can inspect certificates and persist trust in the macOS trust store.
* **Automatic Reference Counting (ARC) Migration**: Migrated the Objective-C codebase from legacy Manual Reference Counting to Automatic Reference Counting (ARC) for improved memory safety, stability, and leak prevention.
* **Hardened VNC Password Storage & Secure State**: Eliminated a potential race condition when setting permissions on stored VNC password files and opted into macOS secure restorable state.
* **Cleaner Launch & Console Output**: Resolved AppKit and CoreUI runtime warnings on launch and disabled verbose internal assertion logging in the bundled FreeRDP libraries.

### 🛠️ CI & Build Infrastructure
* **Automated Security Scanning & Signed Branch Builds**: Added CodeQL static analysis, automated dependency updates, and Developer ID signing and notarization for branch DMG builds.
