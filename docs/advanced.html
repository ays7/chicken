Advanced Usage

Beyond standard remote desktop viewing, Chicken Fork provides modern macOS integration features designed for power users and system administrators.

Dynamic Desktop Resizing

Chicken Fork supports dynamic remote resolution resizing across both VNC and RDP sessions:

  • Microsoft RDP: Powered by FreeRDP's DisplayControl extension. Simply drag the corner of your session window to resize it; Windows instantly reconfigures its desktop geometry to match your window size without disconnecting.
  • VNC / RFB: On VNC servers supporting the Extended Desktop Size protocol extension, resizing the session window sends a desktop geometry update to resize the remote framebuffer on the fly.

Clipboard Sharing & UTF-8 Extended Clipboard

Legacy VNC clients were notoriously restricted to Latin-1 ASCII text. Chicken Fork modernizes clipboard exchange with full UTF-8 Extended Clipboard support:

  • Full Unicode Support: Seamlessly copy and paste international text, accented characters, Chinese/Japanese/Korean scripts, and emoji between macOS and remote sessions.
  • Automatic Focus Synchronization: Chicken Fork automatically synchronizes the local macOS clipboard with the remote session when the session window gains focus, or right before sending middle-click events.
  • Paste Options:
    • Paste (⌘ + V): Simulates keyboard strokes typing the local clipboard text into the active remote application. Useful when pasting into terminals that intercept clipboard shortcuts.
    • Paste to Remote Clipboard: Injects text directly into the remote operating system's internal clipboard without typing.

Fullscreen Spaces & Space Management

Chicken Fork integrates with native macOS Spaces Full Screen mode:

  • Toggling Fullscreen: Press ⌘ + ⌥ + ⌃ + ` (or the green window zoom button). The back-quote key (`) is located immediately to the left of the 1 key on standard keyboards. You can rebind this shortcut in Preferences.
  • Space Isolation (Multi-Session Safety): Chicken Fork disables aggressive window tabbing, ensuring that opening new connections, bookmarks, or dialogs while a session is fullscreen will not hijack the active fullscreen Space.

Touch Bar Integration MacBook Pro

On MacBook Pro models equipped with a Touch Bar, Chicken Fork surfaces handy interactive controls:

  • Session Switcher: Quickly jump between multiple concurrent remote sessions with dedicated Touch Bar tabs.
  • One-Tap Quick Connect: Connect to your saved server bookmarks directly from the keyboard.
  • Status Indicators: Active connection state indicators and instant fullscreen toggle buttons.

Apple Remote Desktop (ARD) Authentication

When connecting to modern macOS machines running Screen Sharing or Remote Management, Apple defaults to a proprietary Diffie-Hellman Key Exchange (DHX) and AES encryption scheme requiring a Mac system account.

Chicken Fork integrates native support for Apple Remote Desktop authentication (powered by CryptoSwift). Enter your macOS system username and password into Chicken Fork's connection dialog to authenticate directly — no need to downgrade to legacy VNC password authentication in macOS Sharing settings!

Bonjour Network Discovery

Chicken Fork listens for local network servers advertising themselves via Bonjour (mDNS / Zeroconf) using the _rfb._tcp and _vnc._tcp service types. Discovered Mac and Linux machines automatically populate in your Connection Window sidebar under the Rendezvous/Bonjour section.

Listening (Reverse) Connections

When a remote server is located behind a strict NAT router or firewall where inbound ports cannot be opened, you can use Chicken Fork in Listening Mode:

  1. Choose File → Listen for Server... from the menu bar.
  2. Chicken Fork listens on local port 5500 for incoming connections.
  3. Instruct the remote VNC server to initiate a reverse connection to your IP address on port 5500. Chicken Fork will accept the connection and launch the session window.

Command-Line Reference

Chicken Fork can be invoked directly from the macOS Terminal, scripts, or automations:

# Executable path
cd "/Applications/Chicken Fork.app/Contents/MacOS"
./"Chicken Fork" [options] [server-address]
Argument Description
--RDP Forces connection protocol to Microsoft Remote Desktop (defaults to port 3389).
--VNC Forces connection protocol to VNC / RFB (defaults to port 5900).
--Username <user> Specifies the login username for RDP or Apple ARD VNC sessions.
--Display <num> Specifies the VNC display number (e.g. --Display 1 connects to port 5901).
--Profile <name> Applies a specific named connection profile (e.g. --Profile Windows).
--Shared Requests a shared VNC session, allowing other clients to remain connected.
--ViewOnly Launches session in view-only non-interactive mode.
--Fullscreen Opens the session directly into fullscreen mode.
--Listen Starts Chicken Fork directly in VNC reverse listening mode on port 5500.
rdp://... Direct URL connection: rdp://admin@192.168.1.50:3389
vnc://... Direct URL connection: vnc://user@192.168.1.10:5900
