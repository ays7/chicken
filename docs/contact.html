Credits & Contact

Maintainers & Primary Contributors

Contributor Role & Contributions
Alexey Shakula (@ays7) Current Maintainer (2022–present)
Universal 64-bit Apple Silicon & Intel architecture, native Microsoft Remote Desktop (RDP) client integration via FreeRDP 3.x, Apple Remote Desktop (ARD) authentication, dynamic desktop resizing, UTF-8 extended clipboard, Retina display boundary fixes, Touch Bar integration, and documentation modernization.
Dustin Cartwright Maintainer (2010–2011)
Maintained Chicken 2.1 & 2.2 series, integrated SSH tunneling, upgraded libjpeg-turbo, and authored numerous stability improvements.
Jason Harris Chicken of the VNC Project Manager (2002–2006)
Ported VNCViewer to Mac OS X Cocoa, designed the original user interface, added core features, and authored initial documentation.
Helmut Maierhofer Original author of VNCViewer for NeXTStep on Intel, encoding architect.
Jared McIntyre GUI additions, Rendezvous / Bonjour server autodiscovery.
Kurt Werle Performance and protocol optimizations.
Sean Kamath Development and feedback.
Cale Peeples Generous creator of the original beloved Chicken mascot icon.
Tobia Conforto Original VNC graphics in About dialog.

Third-Party Open Source Libraries

Chicken Fork is made possible by the dedication of the open-source software community:

Library / Project Purpose License
FreeRDP (v3.32.2) Native Microsoft Remote Desktop Protocol client implementation, graphics pipelines (RFX/EGFX), and virtual channels. Apache 2.0
OpenSSL (v3.x) Static TLS 1.2/1.3 engine and cryptographic cipher implementations. Apache 2.0
CryptoSwift Swift cryptography functions (DHX & AES) powering Apple Remote Desktop (ARD) authentication. Fair Source / BSD
libjpeg-turbo (v3.2.0) SIMD-accelerated JPEG decompression powering the TightVNC encoding. IJG / BSD
AT&T Laboratories Cambridge & D3DES Core RFB protocol structures and DES encryption for standard VNC authentication. GPL
