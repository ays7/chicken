Profiles & Encodings

Connection Profiles allow you to save tailored graphics, compression, mouse emulation, and keyboard mapping settings for different computers or network conditions. For instance, you can use high-bandwidth 32-bit color for local Gigabit LAN connections, while applying aggressive JPEG compression and 8-bit color for remote mobile tethering.

To access the Profile Manager, choose Connection → Connection Profiles... from the menu bar or click the Profile popup in the Connection Window.

Managing Profiles

Profile Management Controls
Profile Selector List

Displays all available profiles. Chicken Fork includes sensible defaults such as Default, Windows, and Low Bandwidth.

Creating & Deleting Profiles

Type a name in the text field below the list and click New to create a new profile. Select an existing custom profile and click Delete to remove it.

Profile Configuration Tabs

1. Encodings Tab VNC

In VNC (RFB), screen updates are compressed using graphical encodings. The more efficient the encoding, the lower the network bandwidth required, at the cost of slight CPU overhead.

ℹ️ Note Regarding RDP Sessions

The Encodings tab applies specifically to VNC sessions. Microsoft RDP connections manage compression automatically using FreeRDP's hardware-assisted RemoteFX (RFX) and Enhanced GFX (EGFX) pipelines.

Encoding Type Characteristics
ZRLE Lossless Zlib Run-Length Encoding. Highly efficient compression for text, code, and graphical user interfaces. Typically the best all-around default for VNC.
Tight Lossy / Lossless Blends 2D compression with JPEG image encoding, accelerated natively on Apple Silicon and Intel via libjpeg-turbo 3.2.0. Ideal for photographic content or remote video.
Zlib / ZlibHex Lossless Standard DEFLATE compression. Solid fallback when connecting to older Unix or embedded VNC servers.
Hextile Lossless Low CPU overhead tile-based encoding, effective on fast local networks with limited CPU resources.
CopyRect Optimization Tells the client to copy existing screen rectangles instead of re-transmitting pixels when windows or text scroll. Always keep enabled.

2. Emulation Tab (Mouse Buttons)

While modern Macs feature multi-touch trackpads and multi-button mice, Chicken Fork provides extensive mouse emulation options for maximum flexibility:

Mouse Emulation Options
No Emulation (Recommended for Modern Macs)

Directly transmits left-click, right-click (secondary click / two-finger tap), and middle-click. Scroll wheel and trackpad two-finger scrolling are passed natively.

Modifier Click

Emulate secondary clicks by holding a chosen modifier key while clicking (e.g. Control + click or Option + click).

Multi-Tap

Emulate a button click by tapping a modifier key (such as ⌘) twice in rapid succession at the current cursor position.

Tap and Click

Tap a modifier key once to enter emulation mode (cursor changes shape), then click to execute the secondary click. Press Esc or wait for timeout to cancel.

3. Modifiers Tab (Keyboard Mapping)

Allows you to map macOS modifier keys (⌘, ⌥, ⌃) to keys expected by remote operating systems:

  • Command Key (⌘): Commonly mapped to Meta on Unix/Linux, Alt on Windows, or the Windows Start Key.
  • Option Key (⌥): By default sent as Alt/Option. Setting this to none (local keymap) prevents Option from being intercepted by the remote server, enabling you to type special macOS accented characters (e.g. ⌥ + e for é).
  • Control Key (⌃): Maps directly to standard remote Control.

4. Colors Tab (Depth & Display Tinting)

Color Settings & Tinting
Color Resolution

Select Let Server Decide (32-bit true color) for pristine visual quality. Over congested networks, dropping to 16-bit (thousands of colors) or 8-bit (256 colors) significantly cuts bandwidth.

Tint Remote Display (Visual Distinguishability)

One of Chicken's most celebrated features! When connecting from a Mac to another Mac, it can be disorienting to know whether a window is on your local machine or the remote screen. Checking Tint remote display tints the remote session with a soft, customizable color wash, eliminating any confusion.
