Frequently Asked Questions

General Questions

What is the difference between Chicken Fork, Chicken, and Chicken of the VNC?

Chicken Fork represents the modern evolution of the classic Mac VNC client:

  • VNCViewer (1998–2000): Original OpenStep implementation created by Helmut Maierhofer.
  • Chicken of the VNC (2002–2006): Cocoa port for Mac OS X by Jason Harris and Geekspiff.
  • Chicken (2010–2011): Independent continuation by Dustin Cartwright adding SSH tunneling and libjpeg-turbo.
  • Chicken Fork (2022–present): Actively maintained fork by Alexey Shakula (@ays7) modernizing the codebase for Apple Silicon (ARM64) and Intel, integrating native Microsoft Remote Desktop (RDP via FreeRDP 3.x), Apple Remote Desktop (ARD) authentication, UTF-8 extended clipboard, dynamic desktop resizing, and Touch Bar controls.
Does Chicken Fork run natively on Apple Silicon?

Yes! Chicken Fork is compiled as a Universal application running natively with 64-bit ARM64 instructions on Apple Silicon as well as x86_64 on Intel Macs.

Protocol & Connection FAQs

Can I connect to Windows and Linux machines using Microsoft Remote Desktop (RDP)?

Yes! Starting in version 2026.11, Chicken Fork includes native RDP support powered by FreeRDP 3.32.2 and OpenSSL 3.x. RDP is especially common on Linux distributions (such as RHEL, Fedora, and Ubuntu) since X11 and classic vncserver were dropped, leaving RDP (via xrdp or gnome-remote-desktop) as the primary way to connect remotely. Select RDP in the connection window, double-click any .rdp file, or connect via rdp:// URLs. See our dedicated RDP Guide for complete instructions.

How do I connect to macOS Screen Sharing or Apple Remote Desktop?

Modern versions of macOS use Apple Remote Desktop (ARD) authentication. In Chicken Fork's connection window, simply enter your macOS username and password. Chicken Fork automatically uses Diffie-Hellman Key Exchange (DHX) and AES encryption to log in securely.

Why did my SSH connection fail with a passphrase-protected private key?

Chicken Fork detects passphrase-protected SSH keys and prompts for input. To avoid repetitive passphrase requests, store your key in the macOS Keychain by running the following command once in Terminal:

ssh-add --apple-use-keychain ~/.ssh/id_ed25519

macOS will securely remember your passphrase and unlock the tunnel automatically.

What is the difference between display number and port number in VNC?

The standard VNC port is 5900 + Display Number. If you enter a number less than 50 in the "Display or port" field, Chicken Fork treats it as a display number (display 0 = port 5900, display 1 = port 5901). If you enter 50 or higher, it is treated as a direct port number. (In RDP mode, port 3389 is used by default).

Input & Clipboard FAQs

Can I copy and paste Unicode, accented characters, and emoji?

Yes! Unlike legacy VNC clients that only supported 7-bit Latin-1 ASCII, Chicken Fork implements the UTF-8 Extended Clipboard protocol extension for VNC and the cliprdr virtual channel for RDP. International scripts and emoji copy and paste seamlessly.

How do I send Ctrl-Alt-Del, Cmd-Opt-Esc, or Windows key combinations?

You can send special keystrokes directly from the menu bar under Connection → Special Keys:

  • Send Ctrl-Alt-Del: For Windows lock / login / task manager screen.
  • Send Cmd-Opt-Esc: For macOS Force Quit dialog.
  • Insert, Delete, Pause, Break, Print Screen: For PC server commands.
How do I type special accented characters or use dead keys?

Open Connection Profiles (⌘ + ⇧ + P), switch to the Modifiers tab, and set the Option key mapping to none (local keymap). This allows your local Mac keyboard to process Option-key combinations (such as ⌥ + e for ´) locally before sending the resulting character to the remote machine.

Community & Contributions

How can I report a bug or request a feature?

All development is tracked on GitHub. Please visit our GitHub Issues page to report bugs, suggest features, or submit pull requests.

How can I help translate Chicken Fork into other languages?

Chicken Fork uses modern Xcode String Catalogs (Localizable.xcstrings). If you speak French, German, Spanish, Japanese, or any other language, you can contribute translations by editing the string catalog in Xcode or as JSON and submitting a pull request on GitHub.
