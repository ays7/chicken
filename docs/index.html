Welcome to Chicken Fork

Chicken Fork is a modernized, high-performance, native remote desktop viewer for macOS. Built upon the storied heritage of Chicken of the VNC, Chicken Fork has been fully modernized to run natively on modern macOS architectures — compiling as a Universal App for Apple Silicon (ARM64) and Intel (x86_64).

Whether you are managing headless Linux servers over VNC, administering Windows workstations over RDP, or screen sharing with another Mac, Chicken Fork provides a streamlined Cocoa interface with low memory footprint and responsive rendering.

Key Highlights

⬇️ Download Latest Release DMG

Get precompiled Universal DMG binaries for macOS (Apple Silicon & Intel) from GitHub Releases.

🖥️ Microsoft RDP Support New

Native Remote Desktop client powered by FreeRDP 3.32.2 and OpenSSL 3.x with NLA/CredSSP, TLS, and .rdp file support.

🌐 Classic & Modern VNC VNC

Supports RFB 3.3–3.8, Apple Remote Desktop (ARD) authentication, Bonjour discovery, and TurboJPEG decompression.

📐 Dynamic Display Resizing

Seamlessly resizes remote desktop resolution when resizing your macOS session window on compatible VNC and RDP hosts.

📋 UTF-8 Extended Clipboard

Copy and paste Unicode text, emoji, and multi-byte characters between macOS and remote sessions with automatic focus synchronization.

🔒 Secure SSH Tunneling

Establish secure, encrypted port-forwarded connections through SSH bastion hosts with built-in macOS Keychain passphrase support.

⚡ Native macOS Integration

Features Touch Bar controls, macOS Spaces fullscreen isolation, Keychain credentials, and granular diagnostic logging.

🏛️ A Brief Heritage Note

Chicken Fork is originally based on Chicken of the VNC by Jason Harris (which was itself adapted from Helmut Maierhofer's NeXTStep VNCViewer), and subsequently maintained as Chicken by Dustin Cartwright. Since 2022, Chicken Fork has been actively maintained and modernized by Alexey Shakula (@ays7). Visit our Credits page for complete project lineage.
