Preferences & Shortcuts

Access application preferences at any time by choosing Chicken Fork → Preferences... (or Settings...) from the application menu or by pressing ⌘ + ,.

Preferences Panels

Performance Preferences
Frontmost Connection Performance

Adjusts how frequently the active session window requests framebuffer updates. Keeping this slider towards the right ensures maximum responsiveness and fluid cursor movement.

Background Connection Throttling

Controls refresh rates for inactive background sessions. Setting this slider lower conserves CPU cycles, battery, and bandwidth when multiple connections are open. To completely halt background updates until manually refreshed (via Window → Refresh), move the slider to Only Update Manually.

Fullscreen Preferences
Autoscroll Speed

When connected to a remote display larger than your physical Mac monitor, moving your mouse to the edge of the screen causes the viewport to pan. This slider adjusts the panning velocity.

Display Scrollbars While in Fullscreen

Controls whether explicit vertical and horizontal scrollbars remain visible while in fullscreen mode.

Display Warning Before Entering Fullscreen

By default, Chicken Fork displays a reminder showing the keyboard shortcut to exit fullscreen. If you are familiar with the exit shortcut (⌘ + ⌥ + ⌃ + `), you can disable this dialog.

Keyboard Equivalents & Scenarios
Scenario-Based Key Mappings

Because remote sessions capture keystrokes, Chicken Fork organizes keyboard shortcuts into three distinct window scenarios:

  • Non-Connection Window: Standard macOS shortcuts when managing bookmarks or preferences.
  • Windowed Connection: Active when a remote session is running inside a regular window.
  • Fullscreen Connection: Active when a remote session occupies a macOS fullscreen space.
Customizing a Shortcut

Select the desired scenario from the popup menu, locate the command in the table, double-click its Shortcut cell, and press your desired key combination. To remove a shortcut, press Space.

Restore Defaults

Restores the default keyboard configuration across all three scenarios.

Diagnostic Logging

Chicken Fork includes built-in diagnostic logging levels to facilitate debugging and connection troubleshooting:

Log Level Description Console Output
None Standard silent operational logging. Only critical failures are printed to standard output. Errors only
Basic Logs connection state changes, protocol handshakes (RFB version, FreeRDP connect status), and session lifecycles. Milestone events
Verbose Full diagnostic protocol logging including NLA authentication exchanges, DisplayControl resolution changes, and clipboard channel synchronization. Detailed trace
💡 Viewing Diagnostic Logs

Log output is visible in real-time by launching Chicken Fork from macOS Terminal or using the macOS Console.app filtering for Process: ForkOfTheChicken or subsystem Chicken Fork.
