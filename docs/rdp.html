Microsoft Remote Desktop (RDP) New in 2026.11

High-performance native RDP client powered by FreeRDP 3.32.2 and OpenSSL 3.x for Windows and Linux.

Connecting to Windows and Linux without breaking a sweat — brawwwK!

Overview

Starting with version 2026.11, Chicken Fork includes full native support for the Microsoft Remote Desktop Protocol (RDP). Powered by statically linked FreeRDP 3.32.2 and OpenSSL 3.x, Chicken Fork connects smoothly to modern Windows Server, Windows 10/11 desktops, and Linux workstations with enterprise-grade security and low-latency graphics.

RDP on Linux

RDP is no longer just for Windows. After Red Hat and other distributions killed X11 along with classic vncserver in favor of Wayland, remote desktop access on Linux shifted heavily toward RDP. Desktops using GNOME (via gnome-remote-desktop) and standalone servers like xrdp now rely on RDP for remote graphical sessions.

Chicken Fork provides first-class compatibility with both Windows hosts and Linux RDP servers, delivering hardware-accelerated rendering, dynamic resizing, and secure TLS authentication across platforms.

💡 Why Native RDP in Chicken Fork?

Instead of juggling separate apps for Linux/Mac and Windows, Chicken Fork brings both remote desktop protocols under one native, lightweight macOS application with unified bookmarks, SSH tunneling, and Keychain storage.

Connecting to Windows & Linux Hosts

Initiating an RDP connection in Chicken Fork is simple:

Connection Window — RDP Mode RDP Protocol
1. Protocol Selector

Click the RDP segment at the top of the connection dialog. The interface automatically adapts, hiding VNC-only fields (like Display Number) and showing RDP credentials.

2. Host

Enter the Windows hostname or IP address (e.g. 192.168.1.150, winserver.corp.local, or [2001:db8::1]). RDP automatically defaults to port 3389. You can override the port by appending :port (e.g. winserver.local:3390).

3. Username & Domain

Enter your Windows username. For Active Directory or domain accounts, use standard DOMAIN\username format or simply your username if connecting to a local account.

4. Password & Keychain

Enter the account password. Check Remember Password to securely save your credentials in the encrypted macOS Keychain.

5. Connection Profile

Choose a connection profile (such as Windows or Default). Profiles manage keyboard modifier translations and color depths.

Opening .rdp Files

Chicken Fork registers as a system viewer for standard Remote Desktop Connection files (.rdp):

  • Double-Clicking in Finder: Simply double-click any .rdp connection file exported from Windows or cloud consoles (AWS, Azure). Chicken Fork automatically opens, parses the settings, and starts the session.
  • Menu Bar: Choose File → Open Connection... (⌘ + O) and select an .rdp file.

Chicken Fork automatically parses the server hostname, port, domain, and username from the file, prompting for passwords when required.

Handling rdp:// URL Schemes

You can launch RDP sessions directly from web browsers, custom scripts, Alfred, Raycast, or the Terminal using standard rdp:// URLs:

# Quick connection to host
open "rdp://192.168.1.100"

# With username and custom port
open "rdp://Administrator@winserver.local:3390"

# Direct invocation via Chicken Fork command line
./"Chicken Fork.app/Contents/MacOS/Chicken Fork" rdp://admin@10.0.0.50

Security & Network Level Authentication

Security is paramount when connecting to Windows environments. Chicken Fork's RDP client supports modern enterprise authentication:

Security Mechanism Description Status
NLA / CredSSP Network Level Authentication finishes user authentication before establishing the full RDP session, protecting against DoS and unauthorized access. Enabled by Default
TLS / SSL Encryption Full end-to-end transport layer security powered by static OpenSSL 3.x. Key exchange and cipher suites comply with modern security baselines. Supported
Certificate Verification Chicken Fork inspects server TLS certificates. When connecting to a self-signed server, you will be prompted to verify and trust the certificate fingerprint. Interactive Prompt
Standard RDP Security Legacy RC4/RDP security fallback for older embedded or legacy Windows machines. Fallback

Key Features in RDP Sessions

Dynamic Desktop Resizing

Chicken Fork supports dynamic display resizing via Microsoft's RDP DisplayControl extension. When you resize the Chicken Fork session window on macOS, a dynamic monitor layout update is transmitted to Windows. The Windows remote desktop instantly reorganizes its desktop resolution to match your macOS window dimensions — no reconnecting or logging off required!

Audio Reception & Output

Remote audio is streamed directly to your Mac using Microsoft's RDP Audio Output extension (rdpsnd) powered by macOS AVAudioEngine and CoreAudio. High-fidelity stereo audio plays seamlessly with automatic latency compensation. When opening .rdp connection files, Chicken Fork respects the standard audiomode:i: setting (redirect to client, play on remote server, or mute).

Automatic Clipboard Synchronization

Text, Unicode characters, and rich formatting are automatically synchronized bidirectionally between your Mac clipboard and the remote Windows desktop via the cliprdr channel. Simply press ⌘ + C on macOS and Ctrl + V on Windows.

Synchronized Mouse Cursors

Windows mouse cursor shapes (text selection I-beam, resize arrows, hourglass/spinners, hand pointer) are decoded and drawn directly by macOS for crisp, zero-latency pointer responsiveness.

SSH Gateway & Bastion Tunneling

Need to connect to an internal Windows workstation or server located behind an SSH bastion or firewall? Chicken Fork makes this painless:

  1. Check Tunnel over SSH in the connection window.
  2. Enter the SSH gateway address (e.g. bastion.company.com or user@gateway:2222).
  3. Chicken Fork establishes an encrypted SSH port forward and establishes the RDP connection through the tunnel.

Windows Keyboard Mappings & Shortcuts

Windows uses different modifier conventions than macOS. Chicken Fork provides easy ways to navigate these differences:

Action macOS Keystroke Windows Remote Action
Copy / Paste / Undo Ctrl + C / V / Z Standard Windows copy, paste, and undo.
Windows Start Key ⌘ (in Windows Profile) Opens Windows Start Menu.
Send Ctrl-Alt-Del Menu: Connection → Special Keys → Send Ctrl-Alt-Del Triggers Windows Security / Task Manager screen.
Close Window ⌥ + F4 (or ⌘ + ⌥ + fn + F4) Closes the active Windows application.
Toggle Fullscreen ⌘ + ⌥ + ⌃ + ` Switches the session into macOS Spaces Full Screen.
