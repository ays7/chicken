Version History

The journey from 1998's VNCViewer and 2002's Chicken of the VNC to today's modern Chicken Fork spans over two decades of native macOS remote desktop engineering. Precompiled universal binaries and release disk images are available on GitHub Releases.

Modern Chicken Fork Releases (2026)

Version 2026.11

November 2026 • Latest Release
  • Product Rebrand to Chicken Fork: Renamed project and application to Chicken Fork with updated metadata and branding.
  • Native Microsoft Remote Desktop (RDP): Integrated full RDP client capabilities powered by FreeRDP 3.32.2 and static OpenSSL 3.x. Supports modern Windows Server and Windows 10/11 hosts.
  • Network Level Authentication & TLS: Added support for NLA (CredSSP), TLS encryption, and server certificate verification dialogs.
  • RDP Dynamic Display Resizing: Resizing session windows dynamically updates remote Windows monitor layout via DisplayControl extension.
  • Cursor Shape Synchronization: Real-time synchronization of remote Windows mouse pointer shapes and states.
  • File & URL Associations: Registered Chicken Fork as viewer for .rdp connection files and added handler for rdp:// URL schemes.
  • libjpeg-turbo v3.2.0: Upgraded static JPEG decompression library for faster TightVNC encoding performance on Apple Silicon and modern Intel CPUs.
  • Bridge & Cryptography Modernization: Realigned Swift-Objective-C interoperability headers and optimized cryptographic routines.

Version 2026.9

August 2026
  • Touch Bar Integration: Full Touch Bar support on compatible MacBook Pro models with session switcher, quick connect buttons, and status indicators.
  • Apple Remote Desktop (ARD) Authentication: Native support for macOS Screen Sharing authentication with system username/password using DHX + AES via CryptoSwift.
  • SSH Passphrase Detection: Added detection and guidance for passphrase-protected SSH private keys (ssh-add --apple-use-keychain).
  • Fullscreen Space Isolation: Fixed window collection management so opening dialogs or new connections while in fullscreen does not hijack the active fullscreen Space.
  • Modern XIB Conversion: Migrated legacy binary NIB files to modern Xcode .xib interface definitions.
  • Compiler & Keychain Cleanups: Updated legacy Security/Keychain APIs and resolved compiler deprecation warnings across the codebase.

Version 2026.6

June 2026
  • Apple Silicon Universal Binary: Re-engineered project build pipeline to produce native Universal binaries (arm64 for Apple Silicon and x86_64 for Intel).
  • Dynamic Desktop Resizing: Added support for dynamic resolution changes when resizing VNC connection windows.
  • Retina Display Stability: Fixed an off-by-one boundary checking bug in framebuffer drawing (FrameBufferDrawing) that caused memory out-of-bounds crashes on high-DPI screens.
  • UTF-8 Extended Clipboard: Added support for the VNC extended-clipboard protocol, enabling seamless copy-paste of Unicode and emoji characters.
  • Automatic Clipboard Synchronization: Automatically synchronizes clipboard contents when a session window gains focus or right before sending middle-click events.
  • Space Occlusion Tracking: Modernized window visibility tracking using NSWindowOcclusionStateVisible to eliminate screen artifacts across virtual Spaces.
  • "Liquid Glass" Iconography: Retired the legacy pixelated icon in favor of the ultra-high-resolution 3D glassmorphic Chicken Fork logo.

Legacy Chicken & CotVNC History (2002–2011)

The historical archive of previous releases under project maintainers Dustin Cartwright (2010–2011) and Jason Harris (2002–2006):

Version 2.2b2 (November 19, 2011)
  • Fixed bug with changes to ssh host not being saved in some circumstances.
  • Reduce accesses to Keychain while typing password.
  • Some error messages include the encoding which was likely responsible.
  • Correctly detect password prompt from ssh in more cases.
  • Report error messages with establishing tunneled connection.
Version 2.2b1 (August 5, 2011)
  • Added ability to have Chicken set up SSH tunnels.
  • Reconnections no longer open a new window.
  • Upgraded libjpeg-turbo to version 1.1.1.
  • Minor speed improvements in Hextile and ZlibHex encodings.
  • Servers now saved in property list format.
  • Replaced deprecated Keychain manipulation functions.
Version 2.1.1 (February 12, 2011)
  • Fixed bug with changes to update speed not taking effect immediately.
  • Fixed non-functioning interface elements in Japanese and Italian.
  • Fixed bug with settings for selected server not being saved if it is a Bonjour server.
  • Automatically stops tinting in fullscreen mode.
Version 2.1 (January 3, 2011)
  • Can specify a saved server on the command-line. Added --Listen and --Shared flags.
  • Option to tint remote display for visual distinguishability.
  • Changes to profile encodings now take effect immediately.
  • Improvements to password prompting and fullscreen warning panels.
Version 2.1b1 – 2.1b3 (October – December 2010)
  • Name changed from Chicken of the VNC to Chicken.
  • Initial support for JPEG encoding via libjpeg-turbo.
  • Added Japanese localization.
  • IPv6 address support.
  • Trackpad smooth scrolling and server-side mouse movements.
  • Option in profiles for Option key character modification.
Version 2.0b1 – 2.0b4 (August 2004 – January 2006)
  • Initial Universal Binary release (PowerPC and early Intel).
  • New Connection Manager that stores commonly used servers.
  • Bonjour (Rendezvous) autodiscovery of VNC servers.
  • Added Keychain support and customizable menu key equivalents.
  • Mouse button emulation modes (multi-tap, tap and click).
  • Listening mode for reverse connections behind firewalls.
  • Added handling for vnc:// and rfb:// URLs.
Version 1.2.3 – 1.3.6 (March 2002 – January 2003)
  • Initial Mac OS X release ported from Helmut Maierhofer's NeXTStep VNCViewer.
  • Tight, ZRLE, and Zlib encoding support.
  • Fullscreen auto-scrolling mode.
  • Multi-button mouse and mouse scroll wheel support.
  • Connection Profiles and modifier key mappings.
